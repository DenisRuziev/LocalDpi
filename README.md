# Local DPI

Экспериментальное приложение WPF для Windows 10/11 x64. Интерфейс и настройки работают от имени обычного пользователя. Для запуска WinDivert нужны права администратора.

## Запуск

1. Запустите `LocalDpi-Setup.exe`. Установщик скачает официальный движок и сверит SHA-256 архива и извлечённых файлов. Откройте **Local DPI** через ярлык на рабочем столе или меню «Пуск». Создание ярлыка можно отключить при установке.
2. Для запуска движка откройте приложение с правами администратора через кнопку на главной.
3. Выберите сервисы и нажмите **Подобрать стратегию**. Если готовые профили не прошли проверку, попробуйте **Сгенерировать стратегию**.
4. Сохраните найденный профиль и нажмите **Включить обход**. Кнопка **Остановить** завершает процесс winws2. Полный выход доступен через меню трея.

## Что делает приложение

- Применяет профили zapret2 к TLS по TCP 443. Хостлисты можно редактировать на вкладке **Хостлисты**. Несколько доменов отделяются пробелами или переводами строк. Режим **Все сайты** снимает ограничение по хостлисту после подтверждения, сохраняя проверку на выбранных доменах.
- Для каждого домена открывает прямое TCP-соединение и проверяет TLS 1.2 и 1.3 с системной проверкой сертификата. Профиль считается кандидатом, если по каждому домену прошла хотя бы одна версия, при равенстве сохраняется первый кандидат. Проверяется рукопожатие, поэтому результаты не подтверждают вход в аккаунт, воспроизведение видео или голосовые звонки. На отдельных версиях Windows и у отдельных серверов TLS 1.3 может быть недоступен.
- Перебирает фиксированные профили сегментации и генерирует варианты из документированных параметров zapret2. Это экспериментальные профили. Эффективность зависит от сети.
- Привязывает сохранённый результат к хешу активных сетевых интерфейсов и адресов шлюзов, а также к области обхода. Две сети с одинаковым интерфейсом и адресом шлюза могут разделить профиль.
- Диагностика запускает те же TLS-проверки без обхода. По одному результату нельзя установить, что сбой вызван фильтрацией SNI. Диагностика и подбор останавливают активный профиль.
- Журнал проверок показывает этап сбоя DNS, TCP или TLS. Из диагностики можно открыть сетевые настройки Windows и выбрать DNS для своего адаптера. При наличии `redirector.googlevideo.com` он используется для контрольного подключения. Запись `googlevideo.com` продолжает охватывать поддомены видео в правилах движка.
- Кнопка проверки доступа к нейросетям показывает TLS ChatGPT и HTTP-статусы сайтов и адреса Codex. Проверка выполняет GET-запросы без авторизации, cookie и чтения тела ответа. Статусы 401 и 405 подтверждают наличие ответа от адреса. Доступ к учётной записи проверяется в самом Codex. Заголовок `CF-Ray` можно сохранить вместе с журналом.
- Профиль **Combo / TLS + QUIC + Discord** использует отдельные правила для TLS YouTube, TLS остальных доменов, QUIC и обнаружения голосового UDP Discord. Файлы для этого профиля добавляет установщик.
- Проверка ИИ сравнивает прямой HTTPS с маршрутом через действующий системный прокси Windows, если он настроен для ChatGPT. Сравнение включает ChatGPT, адрес Codex, Claude, Gemini и Grok. Обе серии выполняются без учётной записи.
- Кнопка **Обновить профиль сети** проверяет рабочий профиль или запускает перебор сохранённых и встроенных вариантов, затем генерацию. Успешный результат сохраняется внутри приложения. Если обход включён, новый профиль сразу применяется. При неудаче приложение пытается восстановить предыдущий профиль.
- Подбор, генерация и сетевые проверки выполняются по кнопке. При открытии отображается сохранённый профиль для текущей сети, если он есть.
- Если для разных доменов лучше подходят разные параметры, приложение собирает смешанную стратегию и проверяет её целиком. В режиме «Все сайты» правила для проверенных доменов идут первыми, остальные TLS-соединения по TCP 443 используют общий профиль. Автопроверка охватывает выбранные домены.
- В журнале отображаются локальные события текущего сеанса. Настройки и файлы движка лежат в `%LOCALAPPDATA%\LocalDpi`. Автозапуск открывает только интерфейс в трее.

## Движок

Установщик проверяет зафиксированный хеш архива, затем сверяет четыре бинарных файла Windows x64, два Lua-скрипта и четыре файла для Combo. При запуске приложение повторно сверяет файлы, которые нужны выбранному профилю. [Официальный релиз zapret2 v1.0.7](https://github.com/bol-van/zapret2/releases/tag/v1.0.7) · [Документация движка](https://github.com/bol-van/zapret2/blob/v1.0.7/docs/manual.en.md)

TLS-диагностика обращается напрямую к выбранным доменам через системный DNS. Приложение не отправляет логи и не изменяет настройки сертификатов, Defender и брандмауэра. В этой сборке отсутствуют встроенный MTProto, WARP, настройка DoH/DoT, исключения Defender/брандмауэра и готовые профили Flowseal ALT / VK.

## Сборка из исходников

Нужен .NET 8 SDK. Публикация автономного Windows x64 EXE:

```powershell
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
dotnet publish LocalDpi.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Исходный код оболочки доступен по лицензии MIT. Движок загружается отдельно и сохраняет собственные условия лицензирования.

Для установщика откройте `Setup.iss` в Inno Setup и скомпилируйте его после публикации EXE. При нестандартном расположении EXE укажите его полный путь через `ISCC /DAppExe=...`.

## Обновления

Кнопка **Обновления** открывает последний релиз GitHub. Закройте приложение через меню трея перед установкой новой версии. Тег формата `vMAJOR.MINOR.PATCH` запускает сборку установщика и публикацию SHA‑256 через GitHub Actions. [Релизы Local DPI](https://github.com/DenisRuziev/LocalDpi/releases)
